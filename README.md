# SeekMemory

> 一个让 AI 真的"记得"你的记忆系统。
> 不只是存下来，而是**像人一样记、像人一样忘、像人一样变成某个人**。

<p align="center">
  <i>「你上个月不是说……吗」<br/>—— 这句话，现在 AI 也能说了</i>
</p>

## 为什么它更像人

大多数"AI 记忆"只是**加一个向量库，把所有对话塞进去，每次检索前五条**。
那不是记忆，那是**搜索**。

真正的记忆有五个特征，SeekMemory 把它们都做了。

---

### 1. 会忘 —— 版本时序与遗忘曲线

**人不是数据库。人记得的是印象，不是记录。**

她不会记得你 10 月 18 号晚上 11 点 40 分说了什么，但她会记得**那阵子你不太好**。

```
遗忘曲线      R = e^(−t / S)
              S 随"被想起的次数"增长
情绪增强      那晚你很难过 → 衰减慢十倍
情绪褪色      长期低落 → 细节模糊，情绪标签保留
```

**表现：**

> 你：你还记得上个月我跟你说的那件事吗
> 她：哪件……那阵子你好像不太好，具体说什么我记不清了

**而不是：**

> ~~「10 月 18 日 23:40 你说：我今天被领导骂了」~~

后者是数据库，前者是人。

---

### 2. 会守口 —— Shadow 与 RBAC

**别人告诉她的秘密，她记得"有这么件事"，但内容锁死在当事人那里。**

三层拆分：

```
内容  →  只对当事人可见，永不越界
影子  →  全局可见：「有件事你答应过别人不说」
影响  →  沉淀成人格：「别人的事你守得住」
```

**表现：**

> 你：他上次找你干嘛
> 她：聊了点事。这个不说
>
> 你：（在群里）她跟你说什么了
> 她：这儿不方便

**她不是"不知道"，是"知道但不说"。** 这两者的差别，就是人和其他东西的差别。

---

### 3. 能翻旧账 —— Source 神圣，事实一直在

**她的理解会错，但你说过的原话永远在。**

```
Source  原始对话 → 只追加、不可改、永不删
Memory  她的理解 → 可修订、会出错、能并存
```

所以你们可以吵架：

> 你：我根本没说过讨厌猫
> 她：……你只说过过敏
> 你：对，我是说过敏

**如果连原话都能改，就永远发现不了自己错在哪。**

这是 PowerContext 的核心思想：**证据与结论分离。**

---

### 4. 有层次 —— 缓冲 / 记忆 / 印象 / 人格

**她不是把所有事平铺在一起，而是有层级的。**

```
印象层   你对他这个人的整体感觉     ← 常驻，答"你觉得我怎么样"
  ↑
场景层   某一次具体的经历           ← 检索，答"上次面试呢"
  ↑
细节层   当时说了什么、几点          ← 按需下钻，答"具体几点"
```

外加一个**短期缓冲**：

> 早上你说「我可能要辞职」
> 晚上你说「算了，不辞了」
>
> 她不会记成"他要辞职"——**因为缓冲还没沉淀。**

**表现：**

> 你：你觉得我这个人怎么样
> 她：有点倔。嘴上不饶人，但真有事会帮

这句话不是从某条记录里查出来的，是**很多次经历沉淀出来的印象**。

---

### 5. 会反省 —— 反思与边界

**你不需要纠正她。她自己会发现。**

她不只听你说什么，还听**你接下来说什么**：

```
你说「不是这个意思」        → 她理解错了
你重复解释同一件事          → 她没接住
你回复突然变短              → 她可能说错话了
你追问、接梗、展开          → 她说到点子上了
```

**关键：她会冷处理。** 发现可能错了，先挂起 24 小时——

> 一晚过去还在想：是不是我理解错了
> 第二天你没再提 → 撤案，不记
> 第二天又出现 → 确认，写进「我搞错过的事」

而且**错误会留档，带负权重**：

```
「我以为他讨厌猫，其实只是过敏」  weight = −0.3
```

下次聊到猫，这条会把她往回拽一点。**这就是"顾虑"。**

## 它也省 token

**"更像人"和"更省钱"通常是矛盾的。我们让它们不矛盾。**

| 环节 | 普通做法 | SeekMemory |
|---|---|---|
| 语料注入 | 128 组全塞（~3000 字） | **检索 top-8（~300 字）** |
| 记忆注入 | 全部塞 | 分层：印象常驻，细节按需求 |
| 每轮对话模型调用 | 0 | **0（检索纯本地）** |
| 每晚总结 | 1 次 | 1 次 |
| 每周整理 | — | 2 次 |

**核心：检索在内存里算，不调模型。**

```
每轮对话：  0 次 API 调用
每晚：      1 次（总结）
每周：      2 次（合并 + 复盘）
```

一个月的额外成本，比你随便聊几句还少。

```bash
cd data/plugins
git clone https://github.com/<you>/SeekMemory astrbot_plugin_seekmemory
# 重启 AstrBot
```

配置（WebUI → 插件 → SeekMemory）：

```jsonc
{
  "owner_umo": "napcat:FriendMessage:123456",
  "open_to": "owner_only"
}
```

**没有命令，没有面板。** 你只需要正常聊天，她会自己记事。

想看她记得什么？直接问：

> 你记得我什么

想让她忘？用话跟她说：

> 别提那次了
