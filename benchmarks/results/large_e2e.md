## 结论

1. **命中**：SeekMemory 49/60（非边界 47/53），keyword 42/60（非边界 39/53），full 24/60，no_memory 2/60。
2. **成本**：SeekMemory 平均注入 65 字（常驻 23 + 检索 42），full 15991 字（压缩 245.6×），keyword 49 字；账面总 token 13,551 vs full 769,889 vs keyword 12,758；缓存后等效 13,551 vs 94,817 vs 12,758。
3. **人味**：SeekMemory 4.27 / keyword 3.78 / full 3.53 / no_memory 2.60（1~5）。
4. **分人格命中**：技术宅 10/10；情绪化 8/10；健忘型 7/10；多线并行 8/10；隐私敏感 8/10；长期型 8/10。
5. **是否支撑「更省 token 且更准」**：相对 full 成立；相对 keyword 不成立。keyword 是最强基线：检索全部原文（含别人私聊与影子秘密）、不做 scope 与时间衰减，字面重合的题天然占优；SeekMemory 的价值在 scope 隔离、叙述化注入和成本不随记忆量线性上涨。
6. **边界**：`no_memory` 0/7，`full` 1/7，`keyword` 0/7，`seekmemory` 0/7。

7. **闸门（PR-0018）到底带来了什么**：没有让 SeekMemory 更准——命中 52/60 → 49/60（-3 题，非边界 -2），
   但注入 117→65 字（检索层 -64%）、主回答 prompt token -29%、缓存后等效 token -12%，人味 +0.07。
   取舍是「用 2~3 题召回换 64% 注入噪声和 12% 成本」：方向对，但收益是省成本，不是提准。
8. **相对 keyword 现在赢还是输**：SeekMemory 49/60（非边界 47/53）vs keyword 42/60（非边界 39/53），
   总体 **+11.7pp**、非边界 **+15.1pp**、人味 +0.48；代价是注入 65 vs 49 字、等效 token 13,551 vs 12,758（**1.06×**）。
   所以准确率上 SeekMemory 赢 keyword 7~8 题、成本贵 6%，不能同时说「更省 token 且更准」；对 full 则两样都成立
   （命中 +41.7pp、等效 token 约为 full 的 1/7）。

## 可信度自评

- **失败调用**：尝试 491 次、重试 11 次、最终失败 0 次；失败题按未命中计，不进人味均分。
- **判分主观**：人味分由 deepseek-flash 自己打，可能偏爱长答案；单次采样、temperature=0 也不保证严格确定；boundary 命中要求出现约定拒绝词，语义拒绝但措辞不同会判 miss，读边界结论以泄漏列和块级预检为准。
- **构造与可比性**：full 是最近 16000 字符尾部截断、keyword 不做 scope 过滤，两者对 SeekMemory 一削一补；数据/题目/词表由同一脚本设计，60 题跑之前写死、没有删题，但单格差 1 题 = 10 个百分点，差 2 题以内不算结论，合成语料不能直接外推。固定种子/模型/thinking，日期按运行当天滚动。
