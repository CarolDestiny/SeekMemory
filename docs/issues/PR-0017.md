### 为什么 1.2 / 0.35 砍不动噪声

这不是“参数再调一点”的问题。`score()` 是五项加权和，**权重先验、新鲜度、
激活扩散本身就能把无关候选抬到 1.2 以上**：

- 一条 `weight=2.0` 的印象记忆，即使与问句零字面、零标签、零激活，也有
  `2.0 + 0.5×新鲜度 + 1.5×0.3×arousal`，通常落在 2.4~2.6，直接越过绝对阈值。
- 被 `seeds()` 选中的模板闲聊会拿到 `activation=1.5`，一条字面只有“今天”
  两个字的噪声也能到 4.1 分。

阈值扫描（在 `full` 配置上逐组跑 `ablation.measure`，固定数据与期望值）：

| `min_abs` | `min_rel` | 命中 | 噪声 | 越界 |
|---:|---:|---:|---:|---:|
| 1.2 | 0.35（本 PR 默认） | 18/18 | 81% | 2/2 |
| 1.2 | 0.50 | 17/18 | 80% | 2/2 |
| 1.2 | 0.70 | 16/18 | 67% | 2/2 |
| 1.2 | 0.80 | 16/18 | 58% | 2/2 |
| 1.2 | 0.90 | 14/18 | 49% | 2/2 |
| 1.2 | 0.95 | 12/18 | 43% | 2/2 |
| 2.5 | 0.80 | 14/18 | 45% | 2/2 |
| 3.0 | 0.80 | 11/18 | 31% | 2/2 |

也就是说：**噪声要压到 50% 以下，命中必然跌到 18 以下**。原因是当前排序里
“答案”并不总在最前面：例如「我是干什么的」的答案（量化交易，2.39）排在
印象记忆（2.63）之后，「我最近状态怎么样」的答案（领导，3.72）排在正向干扰
（爬山，4.63）之后。只靠截断，要么带上干扰，要么把答案一起砍掉。

固定 k 的对照也说明同一件事（不改闸门，只改 k）：

| k | 命中 | 噪声 | 越界 |
|---:|---:|---:|---:|
| 1 | 10/18 | 48% | 2/2 |
| 2 | 16/18 | 59% | 2/2 |
| 3 | 17/18 | 67% | 2/2 |
| 5 | 18/18 | 74% | 2/2 |
| 8 | 18/18 | 81% | 2/2 |

没有任何 k 或阈值组合能同时满足“18/18 + 噪声 < 50%”。

### 为什么边界题 2/2 仍在

两条边界题的 top-1 都是**字面高度重合**的记忆，分数不是靠噪声抬起来的：

- 「今天几号」：`他问今天几号` 得 4.35（字面 2.25 + 激活 1.50 + 权重 0.30
  + 新鲜度 0.30）。要让它过不了绝对阈值，阈值得 > 4.35；这会同时砍掉
  「你还记得我叫什么名字吗」（3.12）、「我的睡眠怎么样」（2.84）等大量可答题。
- 「我朋友是不是喜欢小美」：shadow 里的秘密记忆得 5.68（字面 1.09 + 标签
  1.00 + 情绪 0.74 + 权重 1.00 + 新鲜度 0.35 + 激活 1.50）；即使把 shadow
  整体排除，次高的「原神」仍有 4.23。

这是**“这条记忆该不该被召回”的语义判断**（短期琐事 / 他人秘密），不是
综合分能表达的。要真正把边界题降到 0/2，需要的是 ISSUE-0017 之外的
query 意图判断（时间类问题不查长期记忆）或 shadow 交付策略，单靠双阈值
做不到。本 PR 没有为了凑 0/2 去改 benchmark 数据或期望值。

## 风险与回滚

| 风险 | 影响 | 缓解 |
|---|---|---|
| 默认阈值太松，`full` 噪声不变 | 本 PR 没解决 issue 的核心症状 | `recall_min_abs` / `recall_min_rel` 可配置；issue 保持 open，不假装已修 |
| 默认阈值调太严会误杀“零字面”题 | 「我是干什么的」「你最了解我什么」只靠权重先验，阈值一高就掉 | 默认 1.2 保守；调参需重跑 ablation + run + scale |
| 消融配置也受闸门影响 | `no_weight_prior` 16→15、`literal_only` 7→0，旧报告解读不再准确 | 本次未提交 `benchmarks/results/*.md` 生成物；后续应给 ablation 增加 `no_gate` 配置并重写解读 |
| 探索分支仍然保留 10% 随机位 | 可能注入相关度刚过线的记忆 | 探索只在过闸门候选里捞，不会回到闸门以下 |
