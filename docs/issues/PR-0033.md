# PR-0033: Source-assisted retrieval and extraction call budgets

Status: Lead-verified; pending merge.

## Scope

- Added memory-first Source evidence discovery.
- Added pure `recall/source_query.py` returning `SourceHit` ids/hits only.
- Kept `SourceStore.recent_sources()` and revision-scoped
  `ArtifactStore.by_source_ids()`.
- Added `source_recall_enabled`, `source_recall_hours` and
  `source_recall_max_candidates`.
- Reverted extraction chunking to the original turn-only `MAX_TOPIC_TURNS`.
- Kept exact extraction usage accounting.
- Added `dream_max_calls` as the primary Dream budget and retained
  `dream_token_budget` as a secondary guard.
- Added deterministic Dream-only importance triage in `perceive/importance.py`.

## Ownership decision

- SQL remains in `store/sources.py`, `store/artifacts.py` and `store/schema.sql`.
- Source ranking stays in pure `recall/source_query.py`; it returns no Source text.
- `RecallService` / `recall/pipeline.py` remain the single recall entry and apply
  the existing Artifact disclosure/assembly path.
- `IngestService` remains the only extraction writer and owns usage/call accounting.
- `DreamCycle` owns the stop decision; `BackgroundService` wires the callback.
- No new service, manager, registry, DI container or database table.

## Retrieval evidence

- Memory is first. Source evidence is queried only when selected Artifact count is
  below `min(2, recall_k)` and intent is not none.
- At most one `recent_sources` query and one `by_source_ids` batch run.
- Source-derived Artifacts fill only remaining recall capacity and pass existing
  visible/deliverable/valid/window/disclosure rules.
- Pinned persona/impression never gates Source evidence lookup.
- Source text is never in the block, info, logs or assembly.
- `source_recall_enabled=false` preserves the legacy empty-recall info shape.
- Tests: `tests/test_source_query.py`, `tests/test_recall_pipeline.py`.

## Call-budget evidence

- `chunk_turns` is original turn-only behavior; no token chunking.
- `dream_max_calls` (default 12) bounds real `extract()` invocations; unstarted pending
  rows remain recoverable.
- `DreamCycle` passes remaining call and token budgets and records budget/usage/stopped.
- `IngestService.flush` checks the actual token delta before every extraction call;
  `dream_token_budget` has at most one-call slack.
- Exact `usage_in/cached/out` and `usage_snapshot()` are retained, including parse
  failure and partial-success outcomes.
- Tests: `tests/test_absorb.py`, `tests/test_dream.py`.

## Same-session batching evidence

- Dream triage batches already-chunked same-session topics with `dream_batch_tokens`
  (default 6000) plus a reserved prompt estimate.
- One batch is one real extract call; cross-session batching is not attempted because
  extraction evidence validation assumes one session.
- A single oversized topic chunk stays its own call; no turn is dropped or split.
- Batch failure marks all included rows pending; success marks all included rows.
- Multi-topic batches add topic labels; single-topic batches keep default rendering.
- Tests: `tests/test_flush_batches.py`, `tests/test_absorb.py` (including max calls/tokens,
  failure, and cross-session isolation).

## Dream triage evidence

- Pure `perceive/importance.py` scores user turns only with distinct category labels.
  First-person/possessive forms and personal commitment contexts are required for
  identity/preference/relationship/plan; self-recall questions are not extraction
  evidence; assistance commands need a strong personal-memory signal; bare date,
  work, and single-character family/pet terms do not score.
- Fixed threshold 2.0; score/recency/topic-id deterministic ordering; one ranking pass
  per flush drives both selection and metrics.
- Triage runs before provider resolution and model calls; assistant-only, greeting,
  ack and generic low-value topics score below threshold.
- High-value topics are selected for Dream only. Low-value topics remain pending,
  unmarked and undeleted.
- Normal nightly/idle extraction keeps FIFO `select_topic_batches`.
- Journal metadata is category/count only; no text.
- Known tradeoff: user-value selection can narrow self-impression coverage.
- Tests: `tests/test_importance.py`, `tests/test_absorb.py`, `tests/test_dream.py`.

## Risks and rollback

- Source evidence query adds one bounded Source read plus one Artifact batch only when
  Artifact selection is weak; disable with `source_recall_enabled=false`.
- Added indexes are additive and inert.
- `dream_max_calls` bounds actual extraction calls; pending rows remain recoverable.
- Token budget is secondary and may allow one-call slack.
