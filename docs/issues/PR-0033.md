# PR-0033: Token control and Source-backed recent context

Status: implementation complete, pending independent review/merge.

## Scope

- Added a bounded Source fallback after the normal Artifact recall block is empty.
- Added Source-level disclosure decisions and same-session-only raw Source rendering.
- Added `SourceStore.recent_sources()` and `ArtifactStore.by_source_ids()` read ports,
  plus additive `sources(at)` and `artifact_evidence(source)` indexes.
- Added `ContextBudget` Source fields and `ExtractionBudget`.
- Added pair-preserving, turn-and-token-aware `chunk_turns()`.
- Added exact extraction usage accounting to `WriteOutcome` and
  `IngestService.usage_snapshot()`.
- Added Dream token-budget stopping and budget/usage summary fields.

## Ownership decision

- SQL remains in `store/sources.py`, `store/artifacts.py` and `store/schema.sql`.
- Pure ranking and privacy stay in `recall/source_context.py` and
  `core/disclosure.py`.
- `RecallService` / `recall/pipeline.py` remains the single recall composition path.
- `IngestService` remains the single extraction writer and owns usage accumulation.
- `DreamCycle` owns the stop decision; `BackgroundService` only wires the usage callback.
- No new service, manager, registry, DI container or database table was added.

## Privacy evidence

- Cross-session Source text is never rendered raw; the Source disclosure decision
  returns full only for the exact current session.
- Same-session Sources backing active `secret`, `designated` or `shadow` Artifacts
  are excluded from raw rendering.
- Current-query Source text is excluded.
- Raw Source context is bounded by the remaining injection chars and cannot push the
  final block beyond `budget_chars`.
- `source_context_enabled=false` preserves the previous empty-recall info shape and
  does not add Source counters.
- Tests: `tests/test_source_context.py`, `tests/test_recall_pipeline.py`.

## Token-budget evidence

- `chunk_turns()` packs adjacent user/assistant pairs as indivisible units, respects
  both turn and estimated-token limits where possible, and retains oversized units.
- `IngestService` returns exact per-call usage on every post-model outcome and
  accumulates content-free call/in/cached/out counters.
- `DreamCycle` captures usage before the first flush, stops before the next batch at
  the configured budget, records `budget`/`usage`/`stopped`, and still runs
  maintenance for committed work.
- Tests: `tests/test_dream.py`, `tests/test_absorb.py`.

## Risks and rollback

- The Source fallback adds one bounded Source query only when Artifact recall is empty;
  disable with `source_context_enabled=false`.
- Smaller extraction chunks may increase per-topic call count; `dream_token_budget`
  bounds total work and `extraction_chunk_tokens=0` restores turn-only chunking.
- The added indexes are additive and inert for old databases.
- No database table or Artifact schema change; rollback is code/config only.
