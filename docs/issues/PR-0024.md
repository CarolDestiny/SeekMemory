## 问题与行为

原召回只依赖字符 Dice、标签及图激活，在多条常见词干扰记忆之间，带稀有词项的目标可能掉出
top-8。本次增加标准库实现的 BM25，以已有 `RetrievalCandidate.lexical` 补充词面证据。
安装后仍走原检索路径；显式设置 `bm25_enabled=true` 才启用，配置权重冻结为 1.0。

- 字符 bigram 保留词频，不维护人工中文停词表；正文与独立标签分别建倒排表。
  BM25 使用 k1=1.2、b=0.75，分数以 `s/(s+8)` 归一化，再按正文/标签 0.75/0.25 融合。
- 图激活保留，候选按 Artifact ID 去重。N、df、平均长度只来自当前可见候选池。
- 聊天与 WebUI 诊断复用同一长期 Retriever；Cache.version 变化后从活跃缓存重建索引。
  修改、遗忘、恢复和合并会使旧词项失效；诊断继续 dry_run，不消耗指定记忆交付。
- 既有 `Retriever` 协议可供后续扩展，未增加 semantic 占位字段。
  [本地向量提案](../LOCAL-VECTOR-PROPOSAL.md) 仅为待审设计，模型须由用户预装，运行时离线。
- BM25 无新运行依赖、模型、网络调用、SQL 或数据库迁移。既有图/归属/历史路径仍可能读 SQLite。

## 风险与回滚

- 独立合成集仅五题，仍有三题漏召，候选噪声仍为 95%；不能推断真实聊天的整体提升。
- BM25 不解决零 bigram 重合的语义题，ISSUE-0001 保持未解决。
- 建索引、缓存修改后的全量重建和查询均增加 CPU/内存成本；保持默认关闭，待 staging 比较后由 Lead 决定启用。
- 已覆盖无效权重回滚：关闭或未配置开关时不读取 BM25 权重，NaN/inf/无效字符串/None 不影响旧路径。
  启用时非有限数值仍拒绝进入评分，延续宿主外层 fail-open。

关闭 `bm25_enabled` 即恢复 GraphRetriever，无需迁移。合并后需要撤销代码时，
使用 `git revert -m 1 <merge-commit>`。本 PR 未改生产配置、部署、标签或版本号。
