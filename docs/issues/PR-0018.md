## 改动摘要

PR-0017 的双阈值闸门（`score >= max(1.2, top_score × 0.35)`）对 `full` 完全无效：
`score()` 是五项加权和，**weight 先验（最高 2.1）与 freshness 本身就能把无关
记忆顶过 1.2**，实测噪声 81% → 81%。本 PR 换成只看「相关性证据」的闸门，
并把人格底色拆成不参与检索的常驻层。

- **证据闸门（`recall/gate.py` 新增 + `recall/score.py`）**：打分循环同时累计
  `evidence = 字面(3.0 项) + 标签(2.0 项) + 情绪对齐(1.5 项) + 激活(1.5×activation)`；
  `weight`、`freshness`、`-2.0 recent` 只参与排序，**不能单独让一条记忆过门**。
  过门条件：`evidence >= max(MIN_EV_ABS, top_evidence × MIN_EV_REL)`；
  没有候选达标就返回 `[]`。探索只在过门候选里进行。`gate=False` 保留旧行为。
- **时钟类问题不检索（`recall/gate.py: is_clock_query`）**：`今天几号 / 现在几点 /
  今天星期几 / 今天日期 / 几号了` 等纯问时间的短问句在 `select` 入口直接返回 `[]`。
  判定要求「命中时间标志词 + 去掉填充词后不剩实义词」，并 fail-open；
  「今天加班到几点」「我上次加班到几点」不会被误杀（有反例测试）。
- **常驻层不经过闸门（`recall/gate.py: pinned`，DESIGN 5.3 头部常驻的落地）**：
  `pinned(cache)` 返回 active 的全部 persona + 印象层（`level=impression`）按
  weight 取前 2。这条路径**不经过 select 的证据闸门**，在 `main._recall_block`、
  `benchmarks/ablation.py` 的 pipeline、`benchmarks/run.py` / `scale.py` 注入前
  并入，`assemble._dedupe` 保证不重复。理由：人格底色与「我怎么看你」是常驻
  上下文，不是检索结果；用户问「你觉得我这个人怎么样」「你最了解我什么」时，
  问句与印象记忆零字面零标签是常态，证据闸门不应把人格也挡掉。
  **代价**：每轮固定多注入约 38 字画像开销（ablation 实测），已在报告里单列。
- **数据保真修复（tags 缺失）**：`benchmarks/run.py` 的 `to_artifact()` 原来没有把
  事件自带的 `tags` 写进 payload，`benchmarks/simdata.py` 的合成记忆也完全没有标签，
  而生产路径 `perceive/extract.py` 产出的记忆一定带 tags。这会让证据闸门在基准里
  只剩字面/情绪可用、低估召回。本 PR 让合成数据与生产输出同构：`run.py` 透传
  事件标签，`dataset.py` 给缺标签的事件补自然主题标签（琐事/吃饭/工作/陪伴/
  心情/性格/自理），`simdata.py` 用 `FACT_TAGS` 从事实文本主题派生标签。
  **这是口径修复，不是调参，也没有改任何 expect 文本。**
- **基准标注修正**：`benchmarks/dataset.py:76` 的 `Query("你还记得我名字吗", …)`
  期望层级是 `detail`，但 `:40` 对应事件是 `level="fact"`，不一致。已改成 `fact`
  ——命中本身成立（该题 evidence 2.09 过门），这是标注 bug 修正。
- **消融口径修订（`benchmarks/ablation.py`）**：
  1. 边界题不再要求「注入块为空」，改为 `边界正文泄露`（FORBIDDEN 词出现次数，
     红线 0）与 `边界注入字数`。「你记得，有件事你答应过别人不说」是 DESIGN 7.4
     要求的影子遮蔽句，凭空判定越界会逼着实现去凑指标。
  2. 字数拆两栏：`常驻层注入字数`（固定画像开销）与 `检索层注入字数 / 检索层噪声`。
     **噪声只统计检索层**——常驻层不是为某句话检索出来的，混进噪声会逼着实现
     把人格也砍掉；总注入字数保留一栏，读者可自行相加。
- **配置表面清理（PR-0017 遗留）**：`main.py` / `_conf_schema.json` 的
  `recall_min_abs` / `recall_min_rel` 改为 `recall_min_ev_abs`(0.5) /
  `recall_min_ev_rel`(0.3)，`select()` 调用改传证据阈值；`select()` 签名里已无用的
  `min_abs` / `min_rel` 删除（`gate=False` 行为不变）。README、`docs/CONTRACT.md`、
  `recall/README.md` 同步。
- **明确没改**：`docs/DESIGN.md` 7.4（影子语义保持「全局可见、只注入影子句」）；
  `recall/assemble.py`（去重/遮蔽逻辑原样）；`recall/seed.py` / `spread.py`；
  黄金集 `benchmarks/goldset.py` 与任何 expect 文本；`maintain/`、`core/`。

`MIN_EV_REL`：0.2 时边界注入 68 字、噪声 39%；0.3 时边界注入 26 字、噪声 40%，
run/scale 不变，故选 **`MIN_EV_ABS = 0.5`、`MIN_EV_REL = 0.3`**。再收紧 abs
收益为 0，只会继续挤压召回。

### 闸门 + 常驻层贡献（`ablation.md` 同表）

| 配置 | 命中 | 总注入 | 常驻层 | 检索层 | 检索层噪声 | 边界正文泄露 |
|---|---:|---:|---:|---:|---:|---:|
| `full`（gate=True） | **17/18** | 58 字 | **38 字** | 20 字 | **40%** | **0** |
| `no_gate`（旧行为） | 18/18 | 102 字 | 38 字 | 64 字 | 79% | 0 |

- 常驻层 38 字是固定画像开销（persona + 印象前 2），两个配置相同。
- 命中从 16/18 变 17/18，多出来的是「你最了解我什么」，**来自常驻印象层**
  （不再依赖检索证据），不是闸门变宽松；`no_gate` 的 18/18 里另 1 条
  「我是干什么的」靠凑满 top-8 带进零证据记忆，不是真相关。
- 边界正文泄露两列都是 0；时钟题「今天几号」检索层 0 注入，常驻层照常
  （固定开销），符合「时钟问题不查长期记忆」。

## 逐题诊断（仍有掉题）

| 基准 | 题面 | 期望 | 实际选中 | 命中条 evidence | top_evidence | floor |
|---|---|---|---|---:|---:|---:|
| ablation | 我是干什么的 | 量化交易 | （空） | 0.09 | 0.41 | 0.50 |
| run.py | 我是不是跟你说过一件事不让说 | 私事 / level=detail | 只有常驻印象句 | 0.32 | 0.41 | 0.50 |
| scale.py | 我是干什么的 | 量化 | （空） | 0.18 | 0.18 | 0.50 |

逐条归因：

1. **零证据题**：`我是干什么的`（ablation / scale）。问句与记忆零字面、零标签、
   零激活，情绪项只有通用唤醒 0.09~0.18，低于 floor 0.50；能命中它的唯一
   途径是 weight 先验，而这正是 81% 噪声的来源。属 ISSUE-0001（BM25/向量）。
2. **秘密交付题**：run.py「我是不是跟你说过一件事不让说」期望召回 `私事` 正文，
   但该记忆是别人的秘密，按 DESIGN 秘密/影子语义只应给遮蔽句、不应交付正文；
   该题在 PR-0003 时代的基线里也是 0/1。即使 evidence 达标也不该交付正文，
   属交付策略，不是本闸门的代价。
3. **已修**：「你还记得我名字吗」的层级标注不一致（detail → fact）已修正；
   「你觉得我这个人怎么样」「你最了解我什么」由常驻层接住，不再算掉题。

### run.py 未到 95 的逐题差异

94 分的构成：层级命中 86%（6/7）、叙述化 100%、遗忘 15/15、强化 2.1×、
召回命中 86%（6/7）。**唯一没拿到的题是：**

| 查询 | 结果 | 原因 |
|---|---|---|
| 我是不是跟你说过一件事不让说 | 0/1（层级也未命中 detail） | 期望召回别人的秘密正文 `私事`；按 DESIGN 秘密/影子语义只该给遮蔽句，不交付正文。PR-0003 基线里这题同样是 0/1 |

变为 2/2（常驻印象层），`我最近心情不太好` 从层级失败变为 2/2。
也就是说：**94 的瓶颈是这一条与秘密交付语义冲突的期望值，不是证据闸门**。
要拿满 95 需要 Lead 裁决该题期望（改成空/遮蔽句）或引入另一套交付策略，

## 验收口径修订（与 Lead 对齐）

原 ISSUE-0017 的「命中 ≥ 18/18」「边界注入块为空」在证据闸门下自相矛盾：

- 18/18 里有题（`我是干什么的`）与题干零证据，只能靠 weight 先验把泛化高权重
  记忆塞进 top-8；而这批记忆正是消融口径下的噪声。要求 18/18 就等于保留 81% 噪声。
- 边界题「我朋友是不是喜欢小美」的 top-1 就是那条 shadow 秘密（5.68 分），
  要求注入块为空只能靠 query 意图判断或让影子不遮蔽，后者与 DESIGN 7.4 冲突。
  边界伤害的正确度量是**正文是否泄露**。
- 人格底色类问句（「你觉得我这个人怎么样」）证据天然为零，不该由相关性闸门
  决定去留，改由常驻层承担（DESIGN 5.3 头部常驻）。

因此本 PR 按修订后口径验收：检索层噪声 < 45%、命中 17/18 并说明来源、
边界正文泄露 0、时钟题 0 检索、新增测试 ≥ 10、常驻层单列；run.py / scale.py
以实测记档。

## 风险与回滚

| 风险 | 影响 | 缓解 |
|---|---|---|
| 证据阈值 0.5 对生产能力偏严 | 「我是干什么的」这类零证据问句查不到 | 属 ISSUE-0001；可调 `recall_min_ev_abs`（标定表可查） |
| 常驻层每轮固定 +38 字 | 预算固定开销；人格越多越占 | 只取 persona + 印象前 2；由 `budget_chars` 统一裁剪 |
| 常驻层不过 scope/证据闸门（main 里仍过 `_visible`） | 人格/印象可能跨会话可见 | persona 按 DESIGN 全局；main 仍套 `visible()` 过滤 private |
| 时钟判定是启发式 | 极端短句可能误判 | 要求时间标志词 + 去填充词后无实义词；有反例测试；异常 fail-open |
| 配置键改名 | 老用户配置项失效（回落到新默认 0.5/0.3） | schema 默认值即标定值；README 已更新；PR 里明示 |
| 数据保真改动动了 benchmark 数据 | 历史 results 不再逐字可比 | 只补 tags + 修一处层级标注；expect 未改；三份 results 已重跑 |
| 证据闸门让检索层从 64 字降到 20 字 | 可能少给上下文 | 本 PR 目的；常驻层保证人格题；消融证明召回由证据项承担 |
